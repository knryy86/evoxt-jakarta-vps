## 雅加达机房到底在不在印尼本地

这个问题值得单独拎出来，因为市面上有些“印尼VPS”实际把机器放在新加坡，只广播一段印尼 IP。IP 查询显示雅加达，实际物理位置在别处，本地用户访问照样绕路。

Evoxt 雅加达节点的官方描述是接入 **JKT-IX**（雅加达互联网交换中心），并与多家 Tier 1 运营商 peer，对印尼本地和东南亚区域的访问做了优化。

第三方实测的延迟数字能对上这个说法：雅加达本地到新加坡 **16ms**，到香港 **47ms**，到亚洲平均 **111ms**。16ms 到新加坡意味着物理位置确实在雅加达，新加坡机房到新加坡本地一般是个位数毫秒，而从新加坡跨境到雅加达通常要 15ms 以上。

跑印尼本地业务，比如 Shopee、Tokopedia、Lazada 印尼站的落地页，或者面向印尼用户的客服系统，这个延迟水平是够用的。

## IP 属性：能做什么，不能做什么

第三方实测拿到的基础信息：ASN **AS149440**（Evoxt Sdn. Bhd.），IP 段 **23.27.98.0/24**，地理位置印度尼西亚雅加达，类型是 **IDC 机房 IP（广播 IP），不是住宅 IP**。

**风险评分四个来源不一致，得并列看：**

- IP2Location：低风险
- Scamalytics：10/100，低风险
- AbuseIPDB：0
- IPQS：75，可疑

IPQS 给 75 分说明这套 IP 在它的模型里算不上干净，做风控敏感的业务要把这个分数当回事。只看“三家都说低风险”就下单，属于选择性相信。

**IPv4 实测能解锁的：** TikTok 印尼原生、Netflix 印尼原生、YouTube 印尼、Amazon Prime、ChatGPT、Reddit。做 AI API 中转节点的，IPv4 直接可用。IPv6 部分流媒体有屏蔽，主要业务走 IPv4。

**明确不行的三件事：**

1. **TikTok 高风控直播。** 机房 IP 段被平台识别是常态，普通账号矩阵、视频发布、数据采集够用，直播这类严风控场景需要住宅 IP。
2. **邮件服务器。** 25 端口出站默认封禁，发不了信。邮件中转得走 587 或 465 提交端口，配合外部 SMTP 服务。
3. **要求住宅 IP 属性的业务。** 这是广播 IP，属性改不了。

轻量代理、爬虫中转、东南亚本地建站、印尼区流媒体测试，这些用途不受上面三条限制。

差距来自回程路由：

- **联通**：AS149440 → 4837 直连回国，三网里最好的一条。
- **移动**：Softbank → CMI，绕一点但稳定。

主力用户在印尼本地或东南亚 → 延迟 16ms 到新加坡、47ms 到香港，完全够用。

主力用户在中国大陆、以联通移动为主 → 121ms 到 150ms，日常建站、后台管理、数据同步都能接受。

## 哪些人不该买雅加达

**电信主力、业务对延迟敏感。** 264ms 的平均延迟做后台管理可以忍，做实时 API 不行。配 CDN 解决静态资源，动态请求还是绕不开。替代方向是香港或日本节点做前置，或者干脆换节点。

**需要发邮件的。** 25 端口出站封禁，自建邮局这条路走不通。要么用外部 SMTP 服务走 587/465，要么换一家不封 25 端口的商家。

**TikTok 高风控直播。** 机房 IP 属性和住宅 IP 差得远，平台侧识别不看你付了多少钱。这类场景要看带双 ISP 住宅 IP 的方案，越南那几家就是这么定位的。

**国内大带宽下载站、视频分发。** 电信下载跑不满 1Gbps、上传 200Mbps 左右，加上跨境绕行，带宽和延迟都不占优。这类业务该看国内节点或带大带宽保障的海外方案。

**需要泛东南亚多国覆盖的。** 一个雅加达节点覆盖不了新加坡、泰国、越南、菲律宾各自的本地访问。多国节点平台按小时计费，测试成本更低。

## 常见问题

**雅加达延迟为什么比新加坡、香港高？**
物理距离是一部分，主要原因是回程路由。电信走 Softbank 转 163 骨干，国际出口绕行，264ms 是这么来的。联通走 4837 直连，只有 121ms，同一台机器不同运营商差一倍多。

**能装 Windows 吗？**
支持 Linux 全系和 Windows RDP。512MB 和 1GB 内存的套餐跑 Windows 不现实，Windows 建议 4GB 内存起步，也就是 VM-2 及以上。

**能做 TikTok 印尼站吗？**
普通账号运营、视频发布、数据采集可以，IPv4 实测 TikTok 印尼原生。直播这类高风控场景不行，机房 IP 会被识别。

**ChatGPT 能解锁吗？**
IPv4 实测解锁 ChatGPT，做 AI 中转节点可用。IPv6 部分流媒体有屏蔽，业务走 IPv4。

**流量超了怎么办？**
Standard 网络额外流量 $3/TB，可以单独加，不用换套餐。全系 1Gbps 端口，流量额度用完不会限速到低速，按量计费。

**能年付吗？**
支持月付到 3 年付，长期预付单价更划算。建议先月付跑一段时间，确认路由和 IP 符合业务预期再考虑长付。

**需要备案吗？**
服务器在印尼，不需要国内备案。面向印尼本地用户的站点，按当地法规要求处理。

**能跑邮件服务器吗？**
不能。25 端口出站默认封禁，只能走 587/465 提交端口配合外部 SMTP。
